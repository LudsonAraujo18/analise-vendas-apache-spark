# Análise de Vendas com Apache Spark

Projeto desenvolvido para a disciplina de Fundamentos e Técnicas em Ciência de Dados, com o objetivo de aplicar conceitos de processamento e análise de dados utilizando Apache Spark e PySpark.

## Sobre o projeto

O projeto realiza uma análise de dados de vendas de um comércio eletrônico, utilizando uma amostra de 50.000 pedidos entregues.

São realizadas análises de:

- Faturamento por categoria de produto.
- Vendas por mês.
- Formas de pagamento.
- Indicadores gerais de vendas.
- Visualizações gráficas dos resultados.

Também são demonstrados recursos do Apache Spark, como particionamento, execução de consultas e plano físico de execução.

## Tecnologias utilizadas

- Python
- Apache Spark
- PySpark
- Pandas
- Matplotlib
- Google Colab

## Como executar

1. Baixe o dataset [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
2. Extraia os arquivos CSV e compacte-os em um arquivo chamado `olist_dados.zip`.
3. Abra o notebook `analise_vendas_spark.ipynb` no Google Colab.
4. Execute as células na ordem apresentada.
5. Quando solicitado, envie o arquivo `olist_dados.zip`.
